Systemd 
    - system and service manager that runs as the first user-space process (PID 1) to handle system boot and manage running services
    - key features:
        -> Faster boot: starts services in parallel based on dependencies rather than sequential scripts.
        -> Unit management: organizes resources and tasks into units such as service, socket, target, timer, mount, and path.
        -> Process tracking: uses Linux cgroups to reliably track and stop all processes belonging to a service.
        -> Built-in tools: systemctl, journalctl (logging), loginctl (sessions), networkctl (networking), and resolvectl (DNS)
